## 2. 구조 원칙 (개발자 개념을 어디에 쓰나)

- **FBA(기능 폴더)** — 캔버스는 이미 `features/canvas/` 한 기능 폴더다. 편집은 그 안에서 *기능 모듈*로 나눈다: `modules/edits.js`(편집 모델), `modules/elements.js`(요소 고르기 모델), View 는 `canvas_template.html` 의 각 조각 블록. 새 기능 = 새 모듈 또는 새 블록, 기존 블록에 끼워 넣지 않는다.
- **MVVM** — 기존 연결 보기와 같은 층:
  - Model(순수, DOM·저장소·메시지 없음, node 로 unit 테스트): 편집 메모 만들기, 반영 대기 계산(`pendingFor`), 도우미가 바로 쓸 편집 판정(`directOf`), 요소 종류 판정 규칙.
  - ViewModel: 도구 상태(`tool`), 고른 요소, 고른 카드. "의도(intent) → 상태" 한 방향.
  - View: 테두리 그리기, 메뉴, 고치기 칸, 토스트. 이벤트는 의도만 만든다.
- **SoC(관심사 분리)** — 화면 안 DOM 을 아는 것은 `palette.js`(iframe 안) 하나. 캔버스는 메시지(`hd-hit-at` 등)로만 묻는다. 메시지는 **추가만**(절대 규칙 6).
- **단일 진실 원천** — 화면 파일을 바꾸는 편집은 모두 메모 목록(`hd-notes:`) 하나에서 나온다. 판 위 표시(반영 대기 선, 빈 레이아웃 카드, 글자 미리보기)는 메모에서 *계산*한다 — 따로 저장하지 않는다. 되돌리기 = 메모를 넣고 빼기.
- **테스트 층** — contract.md 그대로(고치는 동안 unit + 그 테스트, 커밋 전 영역, 끝에 전체 1회). 새 순수 모듈은 `test_canvas_modules.py` 의 순수성 검사 대상에 넣는다.

## 3. 세로 조각 (순서 = 커밋 순서)

| 조각 | 사용자가 보는 것 | Model | ViewModel / View | 확인 |
|---|---|---|---|---|
| **S0 버그** | 크게 보기에서 다른 화면으로 넘어가면 그 화면 번호만 보인다 | — | palette.js 새 메시지 `hd-here {screen}`(불러올 때) → `mscreen` 갱신 → 핀 다시 | 넘어간 뒤 핀 0개 |
| **S1 모델 분리** | (동작 같음) | `modules/edits.js`: `editNote`·`pendingFor`·`directOf`·`layoutNote` 글귀를 순수 함수로 옮김 | 템플릿은 `HD.edits` 를 부른다 | unit 테스트 + 기존 브라우저 전부 |
| **S2 요소 테두리** | 트리거·주석·글자 도구에서 카드 안 요소에 마우스를 올리면 종류별 테두리 | `modules/elements.js`: `kindOf(tag, role, hasText…)`; palette.js `hd-hit` 에 `kind` 추가 | 마우스 따라 `hd-hit-at`(한 프레임 한 번) → `.phone` 위 테두리 층 | 종류별 테두리 색 |
| **S3 보기(▶)** | 카드 한 번 누르기는 크게 보기를 열지 않는다(카드 고르기). [▶ 보기] 버튼·두 번 누르기 = 크게 보기. 그 안에서 두 번 누르면 글자 고치기 | — | `.anno` → `.pres`, 클릭 규칙 변경, palette.js `hd-dbl`(크게 보기에서 두 번 누른 요소) 추가 | 기존 테스트의 "클릭=확대"를 "▶/두 번"으로 바꿈 |
| **S4 주석 도구(P)** | 도구 막대 주석 도구 → 판 위 요소 누르면 그 요소 메모 팝업 | 메모 대상 = hit | 팝업을 카드 옆에 | 메모 path = 그 요소 |
| **S5 글자 도구(E)** | 글자 위 I 커서, 한 번 누르면 그 자리 고치기. 카드 제목·목적·정책 줄도 | 정책 편집 `edit:'policy', index` · 도우미 `screens.json policies[i]` | 고치기 칸 = 요소 자리·크기·글꼴 맞춤 | 정책 줄 고침 → 메모·반영 대기 |
| **S6 트리거 요소 고르기** | 트리거 도구에서 요소를 누르면 그 요소가 골라지고(테두리 고정) 소켓·메뉴 | 고른 요소 상태 | 고른 요소 테두리 | 고른 뒤 끌기 = 잇기 |
| **S7 카드 고르기·선택 막대** (원 세션 B8~B10) | 카드 누르기 = 고르기(테두리), Ctrl+클릭 여러 장, 고른 카드 위 선택 막대(메모·숨기기·삭제), Del, 카드 메뉴 이름·설명·메모·복제·들어오는 연결 끊기·삭제 | 삭제·복제·들어오는 연결 끊기 메모 | 선택 막대 View | 메뉴·Del·되돌리기 |
