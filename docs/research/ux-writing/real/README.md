**토스와 당근은 문체만으로는 거의 구별되지 않는다** — 차이는 마침표·합니다체 섞임·버튼 짝 같은 작은 신호다. 리디만 뚜렷하게 다르다.

## 가이드와 실제가 다른 점

- **토스**: 이름표 자리는 거의 다 명사형("모든 문구 해요체"는 문장 자리에만 맞음). 대화상자 왼쪽 `닫기`는 6쌍 중 1. 경어("그만하시겠어요?", "도와드릴게요")·수동("로그아웃됐어요")·합니다체("검색 결과가 없습니다.")가 남아 있음. "쏙!" 같은 감탄.
- **당근**: 합니다체가 경고·자동 메시지 밖에도 섞임("전화번호가 복사되었습니다."). 배제한다던 '완료'("주소 복사가 완료되었어요", "답변 완료")와 수동("복사되었어요")이 많음. 이모지("무엇을 도와드릴까요? 😊").
- **리디**: 해요체 금지가 깨짐 — 요청은 "‑해 주세요", 툴팁·개인화 섹션·질문형 소제목은 해요체. 한 화면 안에서도 섞임(404: "없습니다." 다음 "확인해주세요."). `‑시‑`가 마지막 동사가 아닌 곳에도("구매하신 분은"). 친근한 자리엔 "!".
- 세 곳 모두 띄어쓰기가 흔들린다(해 주세요/해주세요).

## 한계

- 스토어 스크린샷은 홍보용 대표 화면이라 대화상자·토스트·오류가 적다 — 이 자리들은 웹 번들·고객센터에서 왔고, 앱 네이티브 문구와 다를 수 있다(토스는 토스증권 PC 웹에 치우침).
- 로그인 뒤 화면(결제·마이·채팅)과 푸시는 거의 없다.
- 말투 분류는 문장 끝을 보고 기계적으로 셌다.
