# 한 번 보내기가 말하는 것 (task 17 · A2b)

`../contract.md` 의 책임 게이트·테스트 층을 따른다. 이 파일은 그 기능의 규칙만(contract.md 에서 옮김 — task 22).

## 규칙

- 한 번 보내기가 말하는 것(task 17 · A2b, `edits.items` → `request`, 항목 머리·text·요청 세 줄 형식은 그대로 — 머리 끝 ` · no=N[,M…]` 은 `edits.md`(#279), 한 항목으로 묶인 메모들의 번호가 모두 실린다): **빈 레이아웃 = 항목 하나**(R5) — 보낼 목록에 그 `new-screen` 메모가 있으면 같은 화면 메모(편집 아닌 것)는 따로 나가지 않고 `요청:` 아래 `       - 본문`(번호 `n.no` 차례, 질문은 `(질문) `)으로 실리며 함께 '보냄'. 목적도 메모 본문도 없으면(복제 빼고, `edits.emptyLayouts`) 보내기는 그대로 가고 결과 알림 앞에 한 번 `say.emptyLayout`. **같은 글 = 항목 하나**(R6) — 같은 화면·의도·범위·공백 정리한 글의 메모(편집은 하나씩)와 여러 요소 메모는 첫 경로가 `path=`, 나머지는 `   다른 곳: 경로 ("20자 이하 글") · …`. **범위**(R7) — 메모 `n.scope` = `element|screen|all`(없음 = element, 상태 파일 판은 그대로). 메모 창 `#pscope`(말은 `annotation.SCOPES`, 기본 이 요소 · 화면 전체 메모는 이 화면), 요청문 `   범위: 이 화면 전체|모든 화면`, 묶음 줄 `.thsc`(`annotation.scopeWord`), 핀은 그대로. 질문에 고른 답의 새 메모는 질문 메모의 범위를 이어받는다. 덧붙는 줄 차례 = 메모 본문 · 범위 · 다른 곳
