# 접근성 검사 (a11y · view-a11y, R59)

`../contract.md` 의 책임 게이트(오류 탐지 포함)·테스트 층을 따른다. 사용자 결정(10-31): Storybook a11y 패널처럼 한 화면에 axe-core 를 돌려 문제를 쉬운 한국어로 보이고, 문제마다 'AI로 고치기'로 기존 대화창 길에 넘긴다. v1 은 디자이너에게 쓸모 있는 규칙만, axe 는 검사할 때만 읽는다(판을 여는 데는 0).

## 규칙

- **규칙(v1)** — `color-contrast` `button-name` `link-name` `image-alt` `input-image-alt` `label` `select-name` `target-size`. 페이지 단위(`document-title`·`landmark-*`·`region`·`html-has-lang` …)는 시안에서 잡음이라 뺀다. 더하려면 `RULES` 와 `TEXT` 한 줄씩
- **차례·글** — critical > serious > moderate > minor, 같으면 `RULES` 차례. 노드마다 글: 대비 = '글자와 배경 대비가 낮아요 — 지금 2.5:1, 4.5:1 이상 필요'(axe `contrastRatio`·`expectedContrastRatio`, 자세히 = 글자/배경 색) · 이름 없는 단추 · 그림 alt · 누르는 크기(지금 w×h, 24×24 이상) …. 모르는 규칙 = axe `help` 그대로. 요약 '문제 N · 이름 n · 대체 글 n · 대비 n · 크기 n'(노드 수, 묶음은 처음 나온 차례)
- **경로** — `hd.path`(palette.js `pathOf` = 편집·첨부 길과 같은 모양). 없으면 axe target 이 같은 모양(' > ' 조각: `#id` | `tag(.cls)?(:nth-of-type(n))?` | `body`)일 때만, 아니면 null(줄은 남고 핀·테두리·고르기만 없음)
- **부르는 길 = 메시지(hd-a11y)** — 직접 부르기(`iframe.contentDocument`)는 file:// 로 연 판에서 막힌다(Chromium, 2026-10-31 확인: `contentDocument` = null). 메시지는 file:// · 도우미 http 둘 다 같다. axe 주소 = 이 페이지 기준 `axe.min.js`(out 안 — 화면 파일에 태그를 더하지 않음, 실행 중 문서에만)
- **단추** — 크게 보기 머리 줄 `.mbar` 닫기 왼쪽 '접근성'(아이콘 + 글, 닫기와 같은 줄 모양) → 연 화면 검사. 카드 우클릭 '접근성 검사'(`data-act="card-a11y"`, 빈 레이아웃 빼고) = 크게 보기를 열고 틀이 실리면 검사. 판 전체 검사는 v1 에 없음
- **결과 창** — 크게 보기 창 오른쪽(12px), 모자라면 왼쪽, 둘 다 모자라면 창 오른쪽 안 → `HD.popPlace.clamp`. 머리 '접근성 · 요약 · ×' · 줄 = 번호(핀 색) · 문제 글 · 요소 이름(대화창 칩과 같은 말 '글자 · …'·'버튼'·'그림 · 파일 이름') · [AI로 고치기] · 줄 툴팁 = 고치는 법. 배율·창 크기가 바뀌면 다시 놓는다
- **핀** — `#mbox` 안(메모 핀 `#mpins`·고른 요소 테두리와 같은 R57 자리 맞춤: 화면 CSS px × 배율, 굴림은 그냥 따라감) 요소마다 테두리 + 번호 핀, 색 = `--ui-danger`(critical·serious) · `--ui-accent`(moderate) · `--ui-muted`(minor). 새 색 없음. 줄에 올리기·누르기 = 그 테두리 강조 + `#mview` 굴림으로 보이게 · 핀 누르기 = 그 줄 강조
- **AI로 고치기** — 셸 `pick(screen, hit)` = 크게 보기 선택 도구(이동)로 그 요소를 고름(`ML.pick` + `BK.show(modalSel)` — 대화창 요소 칩이 기존 길로 생김) + 의도 `hd-chat-prefill {text}`(view-chat: 입력칸 = 그 글, 커서 끝, 숨긴 창이면 다시 보임). **보내지 않는다** — 사용자가 보고 보낸다. 읽기만 탭 = `HD.readOnly.CONTROLS` 의 `#a11yPanel .a11y-fix`(보내기 규칙 그대로), 검사 자체는 됨(쓰지 않음)
- **문제 없음** — 토스트 '접근성 문제 없음 (v1 규칙 8개 기준)', 창·핀 없음
- **걷기** — Esc(떠 있는 층 `a11y`, `escOnly` — 누르기로는 닫히지 않아 화면·대화창을 쓰는 동안 남는다) · 크게 보기 닫기 · 틀이 다시 실림(다른 화면·새로고침) · 창의 ×. 다시 검사 = 바꿔 그림
- **다른 출처** — 크게 보기 틀 주소가 http(s) 이고 이 페이지와 출처가 다르면(앱 카드 개발 서버) 단추 `aria-disabled` + 툴팁/누르면 토스트 '앱 화면(개발 서버 주소)은 다른 출처라 …'
- **오류 탐지** — `axe.min.js` 없음·못 읽음 = `[hd]` 경고 한 번 + 토스트 '접근성 검사 파일이 없어요 — 다시 빌드해 주세요' · `axe.run` 실패 = 토스트(까닭) · 2초 안에 받았음(`run`) 답 없음 = 토스트(palette.js 없음·옛것 — 다시 빌드) · 30초 넘음 = 토스트 · 결과 모양 깨짐 = `[hd]` + 토스트 · 셸 칸 모자람 = `[hd]` 경고 한 번(검사 없이) · 대화창이 prefill 을 안 받음 = `[hd]` + 토스트(요청 글을 보여 줌) · 고를 수 없는 요소 = 토스트(글은 넣음)
