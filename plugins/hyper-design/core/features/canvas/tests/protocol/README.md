# protocol v1 (draft) = today's HTTP shape

Locked by task 47-1 before 47-2 merges the hub and the helper into one server. `helper.json` (canvas `helper.py`) and `hub.json` (`hd home` → `home/home_server.py`) list every route: method, path, auth, callers, request, response, and the cases replayed in order by `test_protocol_v1.py`. That test starts real child processes on free ports, with a temp HD_HOME, USERPROFILE and HOME and a fake paseo. It checks the status and the response keys and types, not the values. Run it with `python -m pytest plugins/hyper-design/core/features/canvas/tests/protocol` (marked `slow`, about 20 s, most of it rebuilds after apply, restore and delete).

Shape language (`expect.json`): `"str" "int" "num" "bool" "null" "list" "dict" "any"`, unions joined with `|` · `{key: shape}` = object that has these keys (extra keys allowed; `key?` = optional) · `{"$eq": v}` = this exact value · `{"$list": shape, "$min": n}` = every element · `{"$map": shape}` = every value. `expect.status` may be `"dropped"` (connection closed without a reply). `expect.ctype` / `contains` check non-JSON bodies. `request.token` = `false` (none) or a wrong string, `host` overrides Host, `raw` = literal body, `size` = N bytes of junk, `${name}` = a value saved by an earlier case (`save`). A case with `skip` documents a route that is not replayed (native dialog, spawns a build) and names the test that covers it. Cases named `SUSPECTED BUG` record today's behaviour as is. Fix the bug and that case's expectation in the same change.
