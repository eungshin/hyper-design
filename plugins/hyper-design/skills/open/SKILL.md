# hyper-design:open — 프로젝트 열기 · 불러오기 · 새로

**저장 = 링크.** 프로젝트 목록(`~/.hyper-design/projects.json`)은 out 폴더가 어디 있는지만 적는다. 메모·카드 위치 같은 상태는 이미 `<out>/.hd-canvas.json` 에 있으므로, 열면 빌드하고 도우미를 띄우는 것만으로 그대로 돌아온다. 복사하지 않는다.

**경로**: 이 스킬을 불러올 때 표시되는 Base directory의 `../../core`가 공용 폴더다. 맨 처음 한 번 `SK=$(cd "<Base directory>/../../core" && pwd)`로 절대경로를 정하고, 명령은 `python3 $SK/features/hd/hd.py …` 로 부른다(`hd` 가 설치돼 있으면 그것도 같다).

인자: `$ARGUMENTS` = 없음 | `<이름>` | `<out 경로>` | `새로`

## 인자 없음 — 고르기
1. `python3 $SK/features/hd/hd.py projects` — 줄마다 `이름 · out · 주소|꺼짐|없음 · 마지막으로 연 때`.
2. 목록을 그대로 보여 주고 한 번만 묻는다: "어느 프로젝트를 열까요? 이름을 알려 주세요(새로 만들려면 '새로')." `[[ASK]]` — 목록이 비었으면 "저장한 프로젝트가 없어요. PRD 로 새로 만들까요?" 로 묻는다.
3. 답이 오면 아래 해당 절로.

## `<이름>` 또는 `<out 경로>` — 열기
- `python3 $SK/features/hd/hd.py open "<이름|경로>" --no-open` — 환경 변수 `PASEO_AGENT_ID` 가 있으면 `--agent $PASEO_AGENT_ID` 를 붙인다(캔버스의 '보내기'가 이 세션으로 온다).
  - 그 out 을 띄운 도우미가 이미 있으면 그 주소를 그대로 쓴다(새로 띄우지 않음). 없으면 커밋된 캔버스 코드로 빌드(`build_ref.py`)하고 도우미를 떼어 띄운다(로그 `<out>/../helper.log`).
  - 경로로 열면 목록에 없을 때 저절로 넣는다.
- 보고: 여는 주소 한 줄 + "이 주소로 열면 메모의 '보내기'가 이 세션으로 와요"(에이전트를 붙였을 때) 또는 "'보내기'는 `<out>/.hd-queue` 대기열 파일로 가요 — `/hd` 로 읽어요"(안 붙였을 때). 출력 끝에 `떠 있는 도우미는 …로 보내요` 가 있으면 그 줄도 그대로 전한다.
- 새 길(먼저 쓴다 — 위 `--agent`·대기열은 그대로 둠): 이 세션이 캔버스에 접속하면 '보내기'가 터미널·Paseo 없이 이벤트로 온다 — `$SK/features/hd` 를 path 에 넣고 `from hd_sdk import Hub; p = Hub().hello("<이름>")` → `for req in p.requests(): …`(`req.data` = text · notes · path), 일하는 동안 `hd progress "<한 줄>" [--screen <화면>]`(캔버스 칩·대화창에 보임), 끝나면 `p.bye()`. 옛 서버면 `NotYet` — 그때는 위 길. 자세히는 `$SK/features/hd/hd_sdk/contract.md` '접속'.
- 실패하면 오류 한 줄을 그대로 전한다. `없음`(out 폴더가 사라짐)이면 경로를 다시 알려 달라고 한 번 묻는다 — 링크를 지우는 것(`hd forget <이름>`)은 사용자가 말할 때만.

## `새로` — 새 프로젝트
1. 한 번만 묻는다: "PRD(기획 문서)를 붙여 넣거나 파일 경로를 알려 주세요." `[[ASK]]`
2. 받으면 `/hyper-design:go` 를 그 PRD로 그대로 진행한다 — go 의 단계를 여기서 다시 쓰지 않는다. go 가 띄운 도우미가 시작할 때 그 out 을 목록에 넣는다.
3. go 가 끝나면 `python3 $SK/features/hd/hd.py save --out <go 의 out 절대경로>` (사용자가 이름을 말했으면 `--name <이름>`) — 출력된 링크 한 줄(`이름 → out`)을 마지막 보고에 붙인다. 다음부터는 `/hyper-design:open <이름>` 으로 연다.

## 하지 않는 것
- out 폴더나 상태 파일을 복사·이동하지 않는다. 목록에는 링크만.
- 포트를 고르지 않는다(도우미가 빈 포트를 잡는다). 다른 세션이 쓰는 도우미를 끄지 않는다.
